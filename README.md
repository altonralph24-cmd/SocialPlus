Social+

More Than Social.

Connect. Share. Discover. Belong.

Social+ is an ambitious social networking and media platform designed to bring people together in one place. Our goal is to create a modern, accessible, privacy-conscious, and data-friendly platform where people around the world can connect, communicate, share content, and discover communities.

---

🌐 About Social+

Social+ aims to make social networking more meaningful by bringing essential social features together in one platform.

Whether you want to connect with friends, share your moments, discover new content, or participate in communities, Social+ aims to give you a place to belong.

✨ Planned Features

- User Accounts – Create an account and securely log in.
- Personal Profiles – Customize your profile and share information about yourself.
- News Feed – View posts, photos, videos, and updates.
- Friends and Followers – Connect with other users.
- Messaging – Communicate through private messages.
- Media Sharing – Upload and share photos and videos.
- Communities – Join and participate in groups.
- Notifications – Stay updated on activities and interactions.
- Privacy and Security – Manage account privacy and protect user information.
- Data Saver – Help users enjoy Social+ while using less mobile data.
- Content Moderation – Support a safer and more respectful community.

These are planned features and are not necessarily available in the current prototype.

🛠️ Technology Stack

Social+ is planned to use the following technologies:

- Flutter & Dart – Mobile application development.
- Supabase – Database, authentication, and backend services.
- Cloudflare – Infrastructure and supporting services.
- GitHub – Source code management and project collaboration.

The project will prioritize free-tier services where practical during early development.

📱 Development Goals

1. Build an Android application first.
2. Create a clean, simple, and user-friendly interface.
3. Prioritize low-data usage and accessibility.
4. Implement secure user authentication.
5. Develop social networking and media-sharing features.
6. Prepare for future iOS and web support.
